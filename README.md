ISB Plane Landing Tracker

Islamabad International Airport — OPIS

Welcome to ISB Plane Landing Tracker, an independent aviation tracking project designed to monitor aircraft landings at Islamabad International Airport (ISB).

Our mission is to record aircraft arrivals, maintain a landing scoreboard and make aviation information accessible to everyone.

🌍 Project Overview

ISB Plane Landing Tracker aims to provide a public dashboard showing aircraft arriving at Islamabad International Airport.

Every confirmed landing earns 1 point on the landing scoreboard.

🚀 Planned Features

Live aircraft arrival tracking

Automatic landing detection

Flight number identification

Airline identification

Aircraft type and registration

Landing date and time

Total landing counter

Daily landing statistics

Automatic scoreboard updates

Public access on computers and mobile devices
